# wander

终端里的迷你 roguelike。用字符画地牢，`@` 是玩家，在随机生成的房间里探索、战斗。

野生小项目，假期开心就好。

## 运行

```bash
cargo run --release
```

需要真 TTY（交互式终端里跑，不是管道）。

## 操作

```
h j k l     移动（也支持方向键和 y/u/b/n 斜向；怪物挡路时走不过去）
a           范围攻击（8 方向方形范围；空手/骷髅刀 1 格，装备暗影弓 4 格、伤害 ÷2），不位移但消耗回合
空格        原地待机（让怪先动，用来卡位/脱身）
d           下到下一层（仅本层守护者倒下后）
g           结束本局/回商店（死亡或守护者倒下后；结算界面再按一次 g 离开）
w           切换武器（空手 / 骷髅刀 / 暗影弓）
1           使用血瓶（不消耗回合）
2           参悟武林秘籍（不消耗回合）
3           服用蕴气丹（不消耗回合）
q / Esc     退出
```

- 血瓶 `+`：每层 4 个，揣进背包后按 1 回 15 血；杀怪有 1/2 概率掉一个
- 武林秘籍 `M`：每层唯一，按 2 参悟，攻击力提升 100%（8 → 16，整局只能翻倍一次）
- 蕴气丹 `Q`：每层唯一，按 3 服用，消耗 10 血换 10 点血量上限（40 → 50，整局只能服一次）
- 盾牌 `S`：暗影射手死亡时 50% 掉落（带幸运符必掉），捡起满耐久 45；
  手里有盾时格挡所有来袭伤害（每次命中扣 1 点耐久，落空不扣），唯独骷髅穿盾（骷髅攻击比同类小怪高 4 点）；
  再捡到盾牌会「换上新盾」满耐久上手，旧盾保留当前耐久收进背包留存（背包最多 10 面，满了新盾留在原地）；
  手里盾耐久归零碎裂时，自动从背包取耐久最高的一面换上接着用，背包空了才恢复掉血
- 骷髅刀：骷髅死亡时 20% 掉落（带幸运符提升至 80%），只进背包不自动装备（背包单局最多叠 10 把，满了新掉落的留在原地）；
  按 w 装备后攻击固定 +6（可切换为空手）；结算时背包里每把骷髅刀按 500 积分折算，并累计进永久库存（首页展示，暂不带进新局）
- 暗影弓 `B`：暗影射手死亡时 20% 掉落（带幸运符提升至 80%），掉落在原地走过去拾取只进背包不自动装备（背包单局最多叠 10 把，满了留在原地）；
  按 w 装备后攻击范围 4 格、伤害 ÷2（按 a 射击，w 切换空手/骷髅刀）；结算时背包里每把暗影弓按 1000 积分折算，并累计进永久库存（首页展示，暂不带进新局）
- 幸运符（商店购买，5000 积分）：血瓶掉率升至 90%，参悟秘籍有 25% 概率攻击 ×4，暗影射手必掉盾牌，骷髅刀/暗影弓掉率提升至 80%；代价是本局结算积分减半
- 库存：结算时把本局背包里剩下的骷髅刀/暗影弓数量累计进永久库存（原来没有就当作从 0 累加），首页先显示「有/没有」、有则附库存数量；库存里有的武器开局会往本局背包带上 1 件可用的并自动装备（弓与刀都有时优先举弓），可卸可装回，库存其余数量只作展示
- 结算：积分 = (击杀×100 + 剩余血瓶×50 + 背包存量盾牌按耐久折算 + 骷髅刀每把×500 + 暗影弓每把×1000 + 成就积分) × 层数倍率（1层×1 … 5层×5）；
  成就积分：每个基础成就 +100、每个高级成就 +500、八格（基础 4 + 高级 4）全满再 +1000，结算在惩罚之前（随层数倍率与折半）；
  背包里每面盾牌按「当时收进去的耐久 × 2」计分；
  第 1-4 层守护者倒下后可主动结束结算，死亡积分折半；若用了幸运符，再折半一次（均向下取整）；
  最后再加通关奖励：每通过一关（守护者倒下）+500 积分，不受倍率和折半影响；
  积分进余额，开局商店可花

## 特性

- 随机地牢生成：3x3 房间网格 + L 形走道，保证全图连通
- 5 层地牢：每层一个守护者 `D`，杀掉按 d 下楼；怪物血量逐层 ×1→×3、攻击每层 +2，
  近战小怪 4→0 递减，暗影射手 3→7 递增，第 5 层全是远程
- 视野（FOV）：半径 8，布氏线视线遮挡，能看到过的区域有记忆
- 回合制战斗：看到玩家会追击，否则随机游荡
- 两种怪物 AI：近战怪贴脸咬，远程射手 `o` 保持距离放暗影箭，距离 2-3 格后撤、贴身近身反击
- HUD：生命 / 击杀 / 盾牌耐久 / 盾牌存量 / 消息栏

## 结构

- `src/map.rs` — 地图数据结构、随机生成、视野（LOS）
- `src/main.rs` — 实体、游戏状态机、怪物 AI、终端渲染、输入循环
- 64 个无头单测验证地图连通性、移动安全性、五类道具、盾牌攻防与背包存量换盾、骷髅刀掉落与武器切换、5 层怪物曲线与结算倍率

## 依赖

- `crossterm` — 终端控制（raw mode / alternate screen / 按键）
- `rand` — 随机生成
